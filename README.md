# Hermes                                                                                                            
                                                                                                                      
  Hermes es un asistente personal privado. Lo usa una sola persona, su dueño, con su propia cuenta de Google. No es un
  servicio público.                                                                                                   
                                                                                                                      
  ## Política de privacidad                                                                                           
                                                                                                                      
  - Hermes accede a Gmail, Google Calendar, Drive, Docs, Hojas de cálculo y Contactos de su dueño solo para ayudarle  
  en sus propias tareas.                                                                                              
  - Los datos se procesan en el servidor personal del dueño y con el modelo de IA que usa el asistente.               
  - Los datos no se venden, no se comparten con terceros y no se usan para publicidad.                                
  - El acceso se puede retirar en cualquier momento en https://myaccount.google.com/permission
